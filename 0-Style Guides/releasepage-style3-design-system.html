04 — Buttons

CTA styles

Only style — outlined, fills to black on hover
On dark backgrounds — white outline
border-radius: 0px · border: 1.5px solid · text-transform: uppercase · letter-spacing: 0.12em · font-weight: 500

05 — Spacing & Structure

Rhythm tokens

3px — hairline rule weight
12px — element gap
28px — inner padding
80–120px — section padding (maximal)
Section transitions use a 1px gold rule, not background colour changes. Whitespace is the primary structural device — never fill space to fill it.

Do / Don't

DoDon't
Let whitespace do the work of separating contentFill space with decoration, icons, or colour blocks
Use thin gold (1px) rules as the only divider deviceUse background colour changes to separate sections
Keep all CTAs outlined, never filledIntroduce a solid/filled button anywhere on the page
Set location highlights as a single-column listAdd icons or markers next to list items
Reserve Melodrama for large display headings onlyUse the serif for body copy or UI labels
