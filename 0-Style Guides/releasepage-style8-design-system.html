07 — Guardrails

Do / Don't

DoDon't
Open the hero with a belief statement, not a product statementLead with price, lot count, or status badges in the headline
Include the cycling word manifesto block as Section 2Replace it with a standard estate intro paragraph
Include one developer pull-quote between Lot Detail and LifestyleSkip the quote block or attribute it vaguely
Rename How to Buy steps in a human, first-person voiceUse generic step labels like "Enquire / Select / Build"
Keep the stat section restrained — no colour bandAdd a bold colour block to the stats, which undercuts the quiet confidence
